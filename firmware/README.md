# 设备底层固件源码

SC171 开发套件 V3 板端（Ubuntu 20.04，Python 3.8）运行的采集固件。它负责读取全部传感器与摄像头，并按自研二进制 TCP 协议上报到云端平台。

> ⚠️ 当前仓库中**尚未包含**本目录代码——板端固件目前只存在于板子上，需导出后放入（见 [`../docs/目录映射与迁移方案.md`](../docs/目录映射与迁移方案.md) 第四节）。

## 建议的文件组织

```text
firmware/
├── main.py              # 入口：连接平台、登录、主循环上报
├── protocol.py          # 帧编解码（2B 长度 + 2B 类型 + 包体）
├── sensors/
│   ├── sht40.py         # 温湿度       → 0x01 / 0x02
│   ├── bh1750.py        # 光照         → 0x03
│   ├── sgp30.py         # TVOC         → 0x04
│   ├── scd41.py         # CO2          → 0x05
│   ├── pms5003.py       # PM2.5        → 0x06
│   ├── apds9960.py      # 红外接近      → 0x07
│   ├── ld2410c.py       # 存在 / 距离   → 0x08 / 0x09
│   ├── mr60bha1.py      # 呼吸 / 心率   → 0x0A / 0x0B
│   └── photoresistor.py # 光敏电压      → 0x0C
├── camera.py            # 摄像头取流 → CAMERA_FRAME (0x0035)
└── config.json          # 平台地址、did、采集周期、I2C/UART 设备节点
```

## 必须实现的协议行为

| 步骤 | 报文 | 说明 |
| --- | --- | --- |
| 1 | `DEVICE_LOGIN` `0x0003` | 包体 = 2 字节大端长度 + did（UTF-8）。did 必须已在 `s_device` 中存在 |
| 2 | 读 `DEVICE_LOGIN_RESP` `0x0004` | 1 字节状态码；`0x00` 成功，其他值平台会**主动断开连接** |
| 3 | 周期上报 `SENSOR_REPORT` `0x0020` | 包体 = `u8 count` + `count × { u8 类型码, f64 数值, u32 时间戳 }`，建议 1–2 秒一次 |
| 4 | 周期上报 `CAMERA_FRAME` `0x0035` | 包体含宽高、fps、时间戳与 JPEG 数据 |
| 5 | 响应下行 `PWM_SET` `0x0012` | 收到后回 `PWM_SET_RESP` `0x0013`，1 字节状态码 |

## 关键约束

- **单帧总长上限 65535 字节**（含 4 字节头），摄像头 JPEG 超过 65531 字节必须分帧或降质量。当前平台下发 `CAMERA_CONFIG` 时的 quality 默认 45、分辨率默认 480×360，请以此控制单帧体积。
- **必须在平台启动之后再上电连接**。后端启动时会把 `s_device` 中所有设备重置为离线，顺序反了会出现「连接正常但平台显示离线」。
- 传感器在线判定超时为 **15 秒**，上报周期不要长于 2 秒。
- I²C 一条总线可挂全部 I²C 器件（SHT40 `0x44`、BH1750 `0x23`、SGP30 `0x58`、SCD41 `0x62`、APDS-9960 `0x39`，地址不冲突）。
- 串口器件共 3 路（PMS5003 / LD2410C / MR60BHA1）。V3 底板已引出多路 UART/RS232/RS485，一般够用；不足时用 USB-UART 桥扩展。

## 运行

```bash
python3 main.py --config config.json
```
