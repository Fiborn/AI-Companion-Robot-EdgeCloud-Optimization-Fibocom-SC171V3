# AI Companion Robot Admin Stitch Redesign

Stitch project: `projects/10389555290739311879`

## Direction

Create a warm but operational admin console for an AI intelligent companion robot. The app should manage robot presence, conversation quality, visual sensing, voice interaction, sensor context, AI model configuration, and safety alerts. It should feel precise and trustworthy like a device control room, but friendlier and more companion-oriented than a generic industrial IoT dashboard.

## Layout

- Keep the left navigation compact and permanent for robot operations.
- Use an elevated white top bar with restrained controls.
- Home view starts with a full-width robot companion command band, then metrics, then the perception/conversation workspace.
- Cards use 6-8px radius, crisp borders, and subtle shadows.
- The first dashboard band reads as a robot care and interaction console with module shortcuts rather than a landing hero.

## Interaction

- Primary actions should read as robot operation commands.
- Status chips should be scan-friendly and color coded.
- Hover states should lift surfaces slightly without changing layout dimensions.
- Avoid decorative blobs; use grid, data lines, robot signal motifs, camera HUD elements, voice waveforms, and compact module shortcuts instead.

## Typography

- Prefer system UI fonts with clear Chinese rendering.
- Headings are compact and purposeful.
- Numeric values use strong weight and tight line height.
